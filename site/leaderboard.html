How scores are selected

The IMU board includes the methods and target label sets in MOSAIC Tables 2–4 and oneHAR Tables 2–3. Overall Accuracy is recalculated over the same UCI-HAR (6 classes) and RealWorld (8 classes) tasks for every method, with equal weights.

One complete setting is selected per method using a fixed order: oneHAR supervised comparison, MOSAIC full-shot, MOSAIC few-shot, oneHAR leave-one-dataset-out, then MOSAIC zero-shot. The rule does not select the highest score. Training sources, label budgets and splits can differ; * and the visible setting identify these differences. Dataset rankings retain all original settings. Sensor QA retains its own cited tasks and metrics.
