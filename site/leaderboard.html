How scores are selected

Verified measured results replace paper values regardless of the difference. Every included seed must cover every required test subject. Fewer than five complete seeds are marked provisional. Paper values fill remaining cells using the existing fixed source order, independent of score.

Overall Accuracy is the equal-weight mean over UCI-HAR, RealWorld, PAMAP2 and USC-HAD. Each dataset contributes 25%. Class versions, supervision, implementation variants and seed coverage can differ; see * below.

* 数据来源：优先展示本次核验通过的实测 Accuracy，不按与论文的差距择优；尚无可用实测汇总的单元格保留论文值。每项均注明 Our run / Paper。总榜只对 UCI-HAR、RealWorld、PAMAP2、USC-HAD 四项 Accuracy 等权平均，各占 25%；混合来源和不同设置的排名仅作参考。

* 实测与暂定结果：UCI-HAR 使用官方测试集；PAMAP2、USC-HAD、RealWorld 分别覆盖 8、14、15 个测试受试者，采用 LOSO 与独立验证受试者。完整监督结果汇总 5 个种子；未满 5 个完整种子的结果标为 provisional，当前种子数见各单元格。每个计入的种子都已覆盖全部测试受试者，进行中的不完整受试者集合不进入均值。± 为完整种子均值之间的总体标准差；暂定结果后续可能变化。

* 类别与协议：本次实测为 UCI-HAR 6 类、RealWorld 8 类、PAMAP2 12 类、USC-HAD 12 类。论文保留各自类别版本，其中 oneHAR 的 PAMAP2 / USC-HAD 为 9 / 7 类，MOSAIC 为 12 / 12 类。监督训练、LODO、zero-shot、划分和标注预算也存在差异；实测完成不等于已复现论文原协议。统一使用 Accuracy 排名，未将 RealWorld Macro F1 混入总平均。

* 模型适配：TimeLLM 使用作者支持的 GPT-2 分支并新增分类输出；IMU2CLIP 使用可公开获得的社区预训练编码器，其原始预训练来源尚未完全核实；UniTS 使用作者 x64 监督预训练权重；IMUGPT 使用作者文本、动作生成及 IMU 仿真链路，训练集校准后迁移 DeepConvLSTM；SensorLLM 使用独立 MHEALTH 对齐预训练。具体输入、版本和证据见每项 Details。

* oneHAR / CDNet 实测：采用作者 CDNet 的逐数据集监督适配版，保留共同划分与 UCI-HAR / PAMAP2 / USC-HAD / RealWorld 的 6 / 12 / 12 / 8 类；CDNet 主体重新初始化训练，使用冻结的 HHAR LIMU-BERT 与 BERT 文本编码器，未使用作者联合训练的 IMU 权重，未包含论文的 LLM 合成、DQA/DPS/PDS、类别级对比或域对抗训练。采用加速度输入及每样本传感器池化修正。每个种子覆盖全部测试集或全部测试受试者后才计入，按当前完整种子平均；种子数与暂定状态见各单元格。其余缺项仍保留论文值，混合均值仅供参考。

* 实现审查：原仓库源码匹配、关键运算与预测文件核验，不等于完整复现原论文的数据、预训练和训练协议。代码、逐方法差异及实测训练参数见 GitHub 实现审查与 README ↗。

* OneLLM / API：OneLLM 为作者冻结权重在全部受试者上的一次零样本分类评测，非五次独立监督训练，也不同于论文中的监督适配设置。HARGPT、ByMyEyes 仍未付费实跑，保留论文结果；离线接口、冒烟及模拟测试均不计入榜单。
