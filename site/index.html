How scores are selected

The IMU board includes the methods and target label sets in MOSAIC Tables 2–4 and oneHAR Tables 2–3. Overall Accuracy is the equal-weight mean on UCI-HAR, RealWorld, PAMAP2* and USC-HAD*, with one result per dataset per method. PAMAP2 and USC-HAD retain each paper’s class version; see * below.

One complete setting is selected per method using a fixed order: oneHAR supervised comparison, MOSAIC full-shot, MOSAIC few-shot, oneHAR leave-one-dataset-out, then MOSAIC zero-shot. The rule does not select the highest score. Training sources, label budgets and splits can differ; * and the visible setting identify these differences. Dataset rankings retain all original settings.
