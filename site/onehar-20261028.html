3. 输入对照：UCI-HAR

同一原始官方测试分区的2,947个窗口：总加速度输入为 17.44%；身体加速度输入为 75.87%。发布数据接近去除重力后的身体加速度。该对照说明输入处理差异很大，但并不能确定作者的完整预处理流程；两次结果均保留。

4. 未运行项与协议边界

MobiAct：当前项目未找到数据，官网要求邮件申请并签署使用协议。没有填入推测分数。

19项 Cross-Dataset / LODO 训练：本次未运行。发布 checkpoint 不足以验证每个目标是否从训练中排除，完整源数据训练也未执行。

  • 发布模型训练成员与完整数据预处理未充分公开，不能确认独立于其训练数据。
  • 作者测试集采用自己的窗口、类别、位置和划分，不能与站点 Standard 或 LODO 分数混排。
  • 适配实验保留冻结权重，仅用加速度，中心裁剪/边缘填充至2.4秒并重采样到50Hz；按目标测试集传感器位置做标量标准化，属于无监督测试集统计。
  • 适配实验使用各数据集类别文本；新类别不经过训练。BERT 的原始含padding均值池化保持不变。
  • Skoda 使用全部10个右臂传感器，分为两组5位置并平均相似度；此为自定义适配。
  • RealWorld 仅完成仓库自带5位置测试集，未重跑榜单7位置原始数据。
  • Shoaib/MotionSense 使用现有LIMU-BERT 20Hz处理数据并做时间适配；不宣称已建立站点标准划分。
  • DSADS 使用原始19类、UniMiB使用AF-17原始17类；站点中的概括类别不能直接作为这两项的评测标签。

5. 可复跑与核验记录

已修复原 test.py 的缺失逗号和硬编码路径；BERT 权重全部从发布 checkpoint 严格加载，词表从 bert-base-uncased 获取。在19条随机输入的对照中，冻结 LIMU-BERT 缓存与原逐次加载的输出逐元素一致，最大绝对误差为0。19项实验指标均从保存的逐窗口预测独立重算通过。

保留原实现的 batch-size-dependent 位置池化计算；新数据适配使用固定 batch size 256。没有静默修改此公式来提高分数。
