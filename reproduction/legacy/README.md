# Historical calibration and retired experiments

These scripts preserve earlier local experiments and paper-protocol investigations. They are **not** current leaderboard entrypoints, and presence here is not a fidelity approval. The canonical four-dataset suite and method reviews are under `experiments/` and `methods/`. Some earlier scripts use different versions, paths, label sets or surrogate models. Files in `retired/` are explicitly inadmissible as official-method scores. See `evidence/historical_code_inventory.json`.
