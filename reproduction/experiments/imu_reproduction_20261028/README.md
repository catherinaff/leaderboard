# Historical raw-v2 canonical suite

Eight implemented methods were run on UCI-HAR, PAMAP2, WISDM, HHAR and OPPORTUNITY17 gestures without Null. Current main-table UCI/PAMAP cells for DeepConvLSTM, IF-ConvTransformer, LIMU-BERT and UniMTS reuse the audited completed raw-v2 runs. RobustHAR, TinyHAR, Attend&Discriminate and DeepSense remain historical extras outside the current19-method scope. See the method reviews and actual training recipes. No historical score is silently inserted into a different label set or metric.
