# oneHAR / CDNet on the common four datasets

The user requested re-enabling One Model to Fit Them All on the exact datasets
used by the other HAR runs on 2026-11-19. MOSAIC remains paused. This independent
queue does not stop or modify other training jobs.

The shared canonical arrays and frozen split files are reused by symlink:
UCI-HAR 6 classes / official test, PAMAP2 12 classes / all8 LOSO subjects,
USC-HAD 12 classes / all14 LOSO subjects, RealWorld 8 classes / all15 LOSO
subjects. Seeds:42,123,2021,2024,3407. Total190 seed/fold jobs. Validation,
training-only median/z-score, selection metric, scheduler, patience and saved
predictions are handled by the existing canonical runner, without changes.

## Scope of the method

This is the author CDNet architecture under per-dataset supervised training.
It is not the complete paper joint-training and synthetic-data experiment.
No paid LLM calls, invented synthetic data, merged labels or class filtering.
The released joint-trained IMU/projection weights are not reused: their target
training membership is unknown. Only the author HHAR LIMU-BERT checkpoint and
frozen BERT language encoder are retained. Trainable CDNet parameters are newly
initialized for every stated seed/fold. Native6/8/12/12 class descriptions form
the frozen language prototypes; supervised cosine cross-entropy trains CDNet.
The per-dataset experiment omits cross-dataset domain loss and the paper's
coarse-category/synthesis objectives; it must be labelled as a supervised adapter.

Acceleration channels are selected according to the author modality: UCI total
acceleration6:9, PAMAP2 acceleration at all3 positions, USC first3 channels, and
RealWorld acceleration at all7 positions. Every original window is retained and
resampled over its full duration to120 points. The extra RealWorld positions
extend the randomly initialized ViT positional embeddings from5 to7.

The author LIMU sensor pooling divides by a sum over the batch as well as sensor
positions. This adapter records a per-sample axis correction to make predictions
independent of other batch members. Frozen LIMU computations are cached in RAM
after verifying cached/uncached author-forward parity and batch invariance for
each fold. Frozen input normalization/position parameters in that detached branch
remain fixed, matching the absence of gradients in the author NumPy path.

Only trainable CDNet weights and small frozen text prototypes are saved in each
fold, avoiding hundreds of duplicate BERT checkpoints. Predictions, splits,
training-only scalers and execution-source hashes remain fully auditable.
No smoke result can become a production score.

## Budget

One bounded GPU1 worker shares the server with existing jobs. Each process is
limited to16% GPU memory. The queue stops launching when disk free is below
34GiB or available RAM below32GiB. The190 lightweight checkpoints are budgeted
before production starts. No existing datasets, checkpoints or caches are deleted.
